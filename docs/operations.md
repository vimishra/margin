# Margin theory of operations

Margin does two jobs, and this document keeps them apart:

- **[Part 1: Notes](#part-1-notes)** is about writing things down and finding them again: the daily note, meetings, people, and keeping the collection tidy.
- **[Part 2: Tasks](#part-2-tasks)** is about deciding what to do and when: writing tasks, planning the day, and the weekly and monthly reviews.

Each part has its own routine for the morning, the day, the week and the month. Follow them as written for two weeks, then change what does not fit. For what each feature does, see the [user guide](user-guide.md).

Shortcuts are for the desktop app. Every one can be changed in Settings → Shortcuts.

## The day at a glance

The two routines interleave. This is the order they run in; the detail for each line is in its part.

| When | Notes | Tasks |
| --- | --- | --- |
| Morning, 5 minutes | Open the journal (⌘J) and glance at yesterday's Log | Read today's task panel, clear anything overdue, settle the Top 3 |
| During the day | Capture with ⌘⇧C; link people and projects as you write | Write anything that needs doing as a task; tick things as you finish |
| Each meeting | ⌘⇧M, link who and what, bullets under Notes, then Decisions | Write each action as a task, with a due date if one was agreed |
| End of day, 2 minutes | Read down today's Log once | Tick what is done; leave the rest |
| Weekly, 15 minutes | Skim the week, refresh people notes, empty Scratch | Clear Overdue, plan from Upcoming and Anytime, catch undated tasks |
| Monthly, 20 minutes | Tidy tags, notebooks and templates; back up | Review Someday, read the Logbook, close finished projects |

# Part 1: Notes

## How notes work

Three ideas carry this half.

1. **The daily note is the front door.** Everything that happens today starts there or is linked from there: a running Log, and a link to each meeting.
2. **Capture first, sort later.** Getting a thought down takes one keystroke. Deciding where it belongs happens once, at the end of the day.
3. **Link, don't file.** Write `[[Project]]` or `[[Person]]` in whatever you are writing. Each note's backlinks then show everything that mentions it, so you rarely need to move a note into the "right" folder.

## Notes: every morning

1. **Open the journal: ⌘J.** Today is at the top, earlier days below.
2. **Scroll down one day** and glance at yesterday's Log, in case something there needs a follow-up today.

That is all for notes. The rest of the morning belongs to [tasks](#tasks-every-morning).

## Notes: during the day

- **Something comes to mind:** ⌘⇧C (or ⌃⌥Space from any other app), type it, press Enter. It lands in today's Log with the time. Do not stop to file it.
- **You are writing about a project or a person:** link them. Type `[[` and the name.
- **You need to find something:** ⌘K and type. A name, a `#tag`, or a date such as "last friday" all work.
- **Something to keep for a few days only** (a number, a draft, a command): ⌘⌥N for a scratch note. It removes itself after a week.
- **An article or source worth reading properly:** New → Research note, and paste the link.

## Notes: every meeting

1. **As it starts: ⌘⇧M,** type the meeting's name, press Enter. The note is created, filed under Meetings by month, and linked from today's Log with the time.
2. **Fill in "Who".** Write people as links: `[[Priya Sharma]]`.
3. **Link the project** once, anywhere in the note: `[[Atlas]]`. This is what makes the meeting findable from the project later.
4. **During the meeting, write only under Notes,** as short bullets. Do not tidy as you go.
5. **In the last two minutes, fill in Decisions:** one line for each thing that was settled.
6. **Afterwards, do nothing.** The meeting is reachable from today's note, from the project's backlinks and from each person's backlinks.

Actions agreed in the meeting are tasks: see [Tasks: in a meeting](#tasks-in-a-meeting).

## Notes: every 1:1

Keep one note per person. Create it once with ⌘K → "New person note", and pin the people you meet every week.

1. **Between meetings,** whenever something comes up for that person: ⌘⇧C, press Tab until the destination is "A note…", choose their note and the "Next time" heading. Margin remembers the choice, so next time it is Tab and Enter.
2. **As the 1:1 starts,** open their note and run ⌘K → "Add today's meeting entry". A dated heading appears at the top of Meetings.
3. **Work down "Next time".** Delete each line as you cover it, and write what was said under today's entry.
4. **Before you close the note,** add anything that must wait to "Next time".

## Notes: end of the day

1. **Open today's note: ⌘D.**
2. **Read down the Log once.** For each line, ask whether it is finished, worth keeping, or something to do:
   - worth keeping: move it into the note for that project or person, or give it its own note and link it
   - something to do: make it a task (⌘⇧9); from then on it belongs to Part 2
   - finished: leave it
3. **Stop.** There is nothing to file and nothing to close.

## Notes: every week

Pick a fixed time: Friday afternoon or Monday morning.

1. **Skim the week.** ⌘J and scroll back through the week. Anything lasting that is still sitting in a Log belongs in a project or person note; move it there.
2. **Check people.** Open the note of each person you meet weekly and make sure "Next time" is current.
3. **Empty Scratch.** Open Scratch in the sidebar and press Keep on anything worth keeping. The rest expires.
4. **Close out reading.** In Research, set anything you have finished to Done.
5. **Reset the pins.** Pin what next week needs; unpin what is finished.

## Notes: every month

1. **Tidy tags.** Look at the Tags list in the sidebar. Two tags that mean the same thing should become one: open the notes under the rarer tag and retag them (⌘T).
2. **Tidy notebooks.** A notebook with one or two notes is rarely worth having. Move those notes up a level.
3. **Tune the templates.** If you delete the same section from every meeting note or daily note, remove it from the template in the Templates notebook.
4. **Back up.** Your notes are a folder of files. Make sure that folder is included in your backup, or copy it somewhere safe now.
5. **Update Margin** if there is a newer version on the releases page.

## Notes: where things go

| You have | Put it | How |
| --- | --- | --- |
| A passing thought | Today's Log | ⌘⇧C |
| A thing to raise with a person | Their note, under Next time | ⌘⇧C → A note… |
| What was said in a meeting | A meeting note | ⌘⇧M |
| Something needed for a few days | A scratch note | ⌘⌥N |
| An article or source | A research note | New → Research note |
| Lasting knowledge about a project | The project's own note | ⌘N, then link it |

Rules of thumb:

- **If you would look for it by date,** it belongs in the daily note.
- **If you would look for it by name,** it deserves its own note.
- **When unsure, capture it.** Sorting it out is what the end-of-day read-through is for.

## Notes: keys

| Do this | Key |
| --- | --- |
| Journal (all days on one page) | ⌘J |
| Today's note | ⌘D |
| Search, switch, run a command | ⌘K |
| Quick capture | ⌘⇧C, or ⌃⌥Space from another app |
| New meeting note | ⌘⇧M |
| New note | ⌘N |
| New scratch note | ⌘⌥N |
| Link to a note | `[[` |
| Add a tag | ⌘T |
| Heading 1 to 5 | ⌘1 to ⌘5 |

# Part 2: Tasks

## How tasks work

Four ideas carry this half.

1. **A task is a checkbox, and it lives where it came from.** An action from a meeting stays in that meeting's note. You never copy tasks into a list; the Tasks view and today's note gather them for you.
2. **A task has two dates, and they mean different things.**
   - The **planned day** is when you intend to start. Until then the task waits in Upcoming; from that day it sits in Today until you tick it. It never becomes overdue.
   - The **due date** is a real deadline. Only a missed due date is overdue.
3. **Someday is a parking place.** A task marked Someday stays out of Today, Upcoming and Anytime until you give it a day.
4. **The Top 3 is today's commitment.** It is a short checklist at the top of the daily note, and what you do not finish moves to the next day by itself.

## Tasks: writing one

- **In a note:** press ⌘⇧9 on a line, or type `/task`, or write `- [ ] ` yourself.
- **From anywhere:** ⌘⇧C and start the line with `- [ ] `. It goes into today's note as a task.

Then add only the details the task needs. With the cursor on the task:

| Add | Key | When to use it |
| --- | --- | --- |
| A planned day | ⌘⇧S | Only if it cannot start now |
| A due date | ⌘⇧D | Only if there is a real deadline |
| A priority | ⌘⇧P | Only if it matters more than its neighbours |
| A tag | type `#name` | To gather tasks across notes |

Most tasks need none of these. A task with no dates is in Anytime: something you could do now.

## Tasks: every morning

1. **Read the "Tasks for this day" panel** at the top of today's note (⌘J or ⌘D). It lists, from every note:
   - tasks due or planned for today
   - tasks from earlier days that are still open
   - anything overdue
2. **Deal with each overdue task.** Do one of three things: tick it, give it a new due date, or decide it is not happening and delete the line. Do not leave it overdue.
3. **Look ahead: ⌘⇧T, then 2** for Upcoming. If anything there needs to start today, highlight it and press **T**.
4. **Settle the Top 3.** In today's note, the Top 3 should hold at most three things that would make today a success. Items carried over from yesterday count. If there are more than three, push the extras to a later day: cursor on the line, ⌘⇧S, pick a day.

## Tasks: during the day

- **You finish something:** tick it where you see it: ⌘↵ on its line, or its checkbox in the panel.
- **You decide to do something today that was not planned:** cursor on the task, ⌘⌥T.
- **Something new needs doing:** write it as a task straight away, in the note you are in or through ⌘⇧C.
- **A task turns out not to be for now:** ⌘⇧S and pick a later day, or Someday.

## Tasks: in a meeting

1. **When an action is agreed, write it at once under Action items,** as a task that starts with the owner: `- [ ] Priya: send the revised numbers`.
2. **In the last two minutes,** go down your own actions:
   - if a deadline was agreed, set it: ⌘⇧D
   - if it has to start on a particular day, set that: ⌘⇧S
3. **Afterwards, do nothing.** Your actions appear in Today or Upcoming on their own, and the task still sits in the meeting note where the context is.

In a 1:1, write actions the same way under that day's entry in the person's note.

## Tasks: end of the day

1. **Tick what you finished,** in the Top 3 and in the panel.
2. **Leave unfinished Top 3 items alone.** They move into tomorrow's note when it is created.
3. **Leave everything else alone too.** A planned task you did not get to stays in Today tomorrow.

## Tasks: every week

This is the review that keeps the lists trustworthy. Open the Tasks view: ⌘⇧T.

1. **Clear what is overdue: press 6.** For each task: do it, give it a new date, or delete it. To push a batch to one day, use **Move all…**.
2. **Read what is coming: press 2** for Upcoming.
3. **Plan the week: press 3** for Anytime, which is everything you could start now.
   - For each thing you intend to do this week, press S and give it a day.
   - For each thing you are not going to do soon, press S and choose Someday.
4. **Catch undated strays: press 9** for No date. Anything here has no plan: give it a day, send it to Someday, or delete it.

## Tasks: every month

1. **Review Someday: ⌘⇧T, then 4.** For each item: give it a real day, leave it, or delete it. This list is only useful if it is short enough to read.
2. **Read the Logbook: press 5,** grouped by date. Scan what you finished this month. It is the easiest source for a status update or a review.
3. **Close finished projects.** Group the Tasks view by Project. A note whose tasks are all done or all stale is a project that has ended: tick or delete the leftovers.
4. **Check your saved filters.** Remove the ones you no longer open.

## Tasks: which list to look at

| You want to know | Open | Key in the Tasks view |
| --- | --- | --- |
| What to do today | Today | 1 |
| What starts later | Upcoming | 2 |
| What you could start now | Anytime | 3 |
| What is parked | Someday | 4 |
| What you finished | Logbook | 5 |
| What you missed | Overdue | 6 |
| What has no plan | No date | 9 |
| Everything open | All open | 0 |

To see one project's tasks, group by Project. To see one topic across projects, type its `#tag` in the narrow-down box, and save it as a filter if you will want it again.

## Tasks: keys

With the cursor on a task in a note:

| Do this | Key |
| --- | --- |
| Make the line a task | ⌘⇧9 |
| Tick or untick | ⌘↵ |
| Move to today | ⌘⌥T |
| When (planned day or Someday) | ⌘⇧S |
| Due date | ⌘⇧D |
| Priority | ⌘⇧P |

In the Tasks view (⌘⇧T), on the highlighted task:

| Do this | Key |
| --- | --- |
| Move between tasks | ↑ ↓ |
| Tick or untick | Space |
| Move to today | T |
| When | S |
| Due date | D |
| Priority | P |
| Open it in its note | ↵ |
| Narrow the list | / |
